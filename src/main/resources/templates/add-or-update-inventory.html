📌 Conditions for adding inventory

  1. Select a Customer first — warehouses load dynamically.
  2. Select a Warehouse configured for that customer.
  3. Enter a valid Item ID that already exists in the system.
  4. Select the correct Item UOM for the item.
  5. Increase By — adds quantity to existing stock.
  6. Decrease By — subtracts quantity from existing stock.
  7. Quantity must be a positive whole number (≥ 1).
  8. Stock cannot go below zero.
